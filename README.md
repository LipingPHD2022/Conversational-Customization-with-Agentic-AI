# Conversational Customization with Agentic AI

Companion materials for **Conversational Customization with Agentic AI: Coordinating Preference Learning and Design Recommendations**, by Yugang Yu and Liping Yang.

The repository contains:

- [Parsing prompts](prompts/) in Chinese and English.
- [Output schema](schemas/) for structured responses.
- [Attribute codes](protocol/) for garment customization.
- [One complete synthetic example](examples/synthetic_case_001/), including requests, responses, and reference results.

Chinese prompts and requests are the original experimental inputs; English files are translations. The models parsed fine-scale replies, and five-level values were derived separately. The example was selected after evaluation to illustrate the method. This release covers the parsing interface and the illustrative case.
